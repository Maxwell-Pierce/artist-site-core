ARTIST STUDIO / USER GUIDE

Troubleshooting

Start with the message in Studio. Export your current work before reconnecting or closing a tab.

Connection and access

SymptomWhat to check
401 / authentication failureToken was copied correctly and has not expired or been revoked.
403 / access deniedCorrect resource owner, selected repository, Contents read/write, organisation approval and your own repository access. GitHub rate limits can also return 403.
404 / not foundRepository spelling, branch name and token access. GitHub can hide inaccessible private resources behind 404 responses.
Studio not enabledThe connected revision needs builder.json with enabled set to true.
Missing required filesThe repository needs artist.json and index.html. Connect to the website repository, not the shared core.
Repository changed / 409 / 422The branch may have advanced, or GitHub rejected the branch update. Export, inspect the branch and reconnect. These status codes can have other validation causes too.

Reading works but publishing fails

Check that Contents is Read and write, that the token is approved, and that repository rules permit direct commits and branch creation. Branch protection can require pull requests or signed commits. Studio currently cannot create a publication PR or bypass those rules. Ask the maintainer for a compatible publication workflow; do not grant broader token permissions as a workaround.

The preview or website did not change

  • Some custom HTML contains hardcoded copy. Only configuration placeholders respond to home-page settings.
  • Site-specific CSS may override a shared colour.
  • Save draft does not publish.
  • After Publish, inspect the repository’s Actions tab for the Pages build/deploy result.
  • Check the live URL in a fresh tab. A browser or network cache can delay what you see.
  • Use Preview music and press Play for audio. If no tracks appear, refresh the saved catalog. For animated entrances or video, test the live website; the visual frame does not run them.

An image is missing

Confirm the file exists with the exact same uppercase/lowercase spelling. Repository image paths begin with assets/; entrance portraits must be local assets. Reconnect after adding new files to refresh the selector. For an external image, use a working public HTTPS URL. Exporting a draft does not include media.

A page cannot publish

Check for duplicate or reserved slugs, a slug matching an existing handcrafted HTML page, a missing title, or an invalid image/link destination. Plain lowercase addresses such as behind-the-music work. Do not include .html in the address field. HTML and executable URL schemes are not supported in structured sections.

Local recovery is unavailable

Use the same browser profile, origin, repository spelling and branch used for the original session. Local drafts do not automatically sync between devices. Private browsing or storage clearing can remove them. If the production branch moved, recovery is blocked; reconcile an exported backup or inspect the saved GitHub draft branch.

A deployment fails

Open the website repository → Actions → Publish artist site. Inspect the failed build or deploy step. Common causes include invalid page data, a conflicting HTML address, missing core revision, Pages configuration, or environment restrictions. The editor cannot repair hosting configuration. Share the workflow URL and error message with the maintainer, but never the access token.

Events or social links are missing

Enable Homepage events and check start/end dates, the device timezone used when entering them, and cancellation status. Expired events are hidden. Remember to Publish. Social profiles require complete valid HTTPS URLs; custom links need labels. Services without a bundled brand icon use a globe. No entries means no public section.

Useful details for support

Record the exact Studio message, the action you took, browser/device, approximate time, and the relevant workflow URL. If needed, provide an exported content draft after reviewing it for unpublished material. Never include the token in screenshots or messages.
