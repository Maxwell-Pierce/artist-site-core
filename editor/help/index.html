ARTIST STUDIO / USER GUIDE

Getting started

Your guide to shaping an artist website, saving your work and publishing it through GitHub Pages.

Your first editing session

  1. Open your website’s /admin/ address.
  2. Create a repository access token using the token setup guide.
  3. Enter your GitHub repository as owner/name, paste the token, and leave the published branch as main unless your website uses another branch.
  4. Select Connect repository. Studio loads the published source files.
  5. Change a headline on Home page. Check the preview, then try Mobile.
  6. Select Save draft to keep a copy in a separate GitHub branch.
  7. Select Publish when you want the changes on your website. Wait for the “live” confirmation.

Understand the three states

Editing changes the preview and attempts a local browser backup. It does not update GitHub or the live site. Save draft writes your content to a separate GitHub branch. Publish commits to the published branch and starts the existing Pages workflow.

You do not need to save a draft before publishing. Publishing includes the current content and page settings together.

What you need

An enabled Artist Studio installation, a site repository containing artist.json and index.html, permission to write to that repository, and an internet connection. Optionally remember your connection on a trusted device for automatic reconnection. The site’s Pages workflow must deploy the configured published branch. Studio runs in your browser and requires no application backend.

What this version includes

Configuration-based home editing, structured extra pages, existing image selection, menu editing, theme controls, responsive visual previews, a persistent preview music player, optional DJ events, social/music footer links, remembered connections, undo, local recovery, JSON export, GitHub draft branches and explicit publication.

Media uploads, arbitrary HTML editing, playlist/lyric management, opening saved draft branches through a dedicated picker, importing exported JSON, and pull-request-based publishing are not included. Existing handcrafted pages remain in your repository and are not converted into editable blocks.

Using this manual

Choose a chapter from the navigation. Use your browser’s Find command to search a chapter. Help opens in a separate tab so you can keep the editor open. No token is needed to read the manual.
