ARTIST STUDIO / USER GUIDE

Edit pages, content & design

Work in the controls on the left and review the result in the visual preview.

Home page

Edit the hero eyebrow, headline, accent line, introduction, image caption, about heading and about text. Text is treated as content, not executable HTML.

These settings update artist.json. Your template must contain the corresponding placeholders, such as {{hero.title}} and {{about.text}}. Text hardcoded into an artist’s custom HTML does not change when its configuration field changes. Ask the template maintainer to add the placeholder if needed.

Identity & entrance

Set the full artist name, its first and second display parts, tagline and search description. Keep the full name and split display name consistent. Entrance settings control the eyebrow, portrait path, portrait description, welcome message, enter button and portrait effect.

Portraits must use an assets/ path. The image selector lists existing repository images. fade is the general-purpose effect; eye-glow uses the existing eye animation and needs suitably positioned artwork. Reduced-motion preferences are respected by the player runtime. The entrance animation itself does not run in Studio’s script-free preview.

Colours & appearance

Choose six colours: background, panels, primary text, secondary text, primary accent and secondary accent. Changes use six-digit hex colours. Keep text readable against backgrounds and check links, buttons and muted copy at mobile width. Artist-specific CSS may override shared colours; those rules remain owned by the site.

Create an extra page

  1. Select New page.
  2. Give it a clear page title and a short menu label.
  3. Set its address, for example my-story. Studio adds .html.
  4. Write the search description.
  5. Choose whether it appears in navigation.
  6. Add, edit and reorder its sections, then review the mobile preview.

Addresses use lowercase letters, numbers and hyphens. They must be unique and cannot replace existing HTML pages or reserved addresses such as index, admin and offline. Changing an address creates a new URL on the next deployment; redirects are not generated automatically. Update links pointing to the old address.

Section types

SectionFields and behaviour
TextOptional heading and plain text. Paragraph line breaks are preserved.
ImageExisting asset path or HTTPS image URL, alternative text and optional caption. Choose from repository images using the selector.
LinkButton label and destination. Use an HTTPS URL, a local HTML page, or an anchor.

Use the arrows to move a section up or down. Remove deletes that section from the current draft. There is no media upload control; add new image files to the repository separately, then reconnect to refresh the image list. External images must remain publicly accessible.

Examples: assets/portrait.webp, https://example.com/photo.webp, story.html, and index.html#music. Links using javascript:, scheme-relative URLs or parent-directory traversal are rejected. Email and telephone schemes are not currently supported.

Menus & page order

In Pages & navigation, select Customise existing menu to start from the current template’s links. Edit labels and destinations, add or remove links, and use the arrows to reorder them. Restore template menu removes your custom base menu and returns to the template’s original links.

Visible generated pages are appended after that base menu. Use the page arrows to set their order. Avoid adding the same generated page to the base menu as well, or you will get duplicate links. Hiding a page from navigation does not make it private: its URL remains accessible after publication.

Delete a page

Select its page editor, choose Delete page, and confirm. It disappears from the current draft; publishing removes it from the next clean build and the generated menu. Existing external links may then lead to a missing page. Undo can restore the edit during the current session.

Preview accurately

The preview uses your artist’s homepage template and stylesheet. Desktop and Mobile change the preview width. Generated pages replace the main content while retaining the artist shell.

Preview is sandboxed: music, scripts, custom interactive behaviour and video playback do not run. It does not reproduce generated playlist content or guarantee exactly the same appearance as every live device. Check the published site for playback, entrance animation and final media behaviour.

Undo

Undo restores earlier editing snapshots, up to 50 per session. It does not undo GitHub commits or a live deployment. There is no Redo button. Export or save a draft before making a large change.
