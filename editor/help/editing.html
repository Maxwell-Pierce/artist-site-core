ARTIST STUDIO / USER GUIDE

Edit pages, content & design

Click the content directly on the page to edit it. Use the compact settings inspector for page addresses, image assets and destinations. Try the visual content editor without connecting GitHub ↗

Home page

Click text on the canvas to edit it in place, including the hero, about, community, collection-section headings, navigation and footer. Select text for formatting beside that selection. Click images and links for their settings; use Media on this page to select decorative video behind overlays. These fields keep the typography of your site template. Add text, image or link sections using the insertion controls at the bottom of the home page; these extra sections can be reordered independently of the existing template.

These settings update artist.json. Your template must contain the corresponding placeholders, such as {{hero.title}} and {{about.text}}. Text hardcoded into an artist’s custom HTML does not change when its configuration field changes. Ask the template maintainer to add the placeholder if needed.

Identity & entrance

Set the full artist name, its first and second display parts, tagline and search description. Keep the full name and split display name consistent. Entrance settings control the eyebrow, portrait path, portrait description, welcome message, enter button and portrait effect.

Portraits must use an assets/ path. The image selector lists existing repository images. fade is the general-purpose effect; eye-glow uses the existing eye animation and needs suitably positioned artwork. Reduced-motion preferences are respected by the player runtime. The entrance animation itself does not run in Studio’s script-free preview.

Colours & appearance

Choose six colours: background, panels, primary text, secondary text, primary accent and secondary accent. Changes use six-digit hex colours. Keep text readable against backgrounds and check links, buttons and muted copy at mobile width. Artist-specific CSS may override shared colours; those rules remain owned by the site.

Create an extra page

  1. Select New page.
  2. Give it a clear page title and a short menu label.
  3. Set its address, for example my-story. Studio adds .html.
  4. Write the search description.
  5. Choose whether it appears in navigation.
  6. Add, edit and reorder its sections, then review the mobile preview.

Addresses use lowercase letters, numbers and hyphens. They must be unique and cannot replace existing HTML pages or reserved addresses such as index, admin and offline. Changing an address creates a new URL on the next deployment; redirects are not generated automatically. Update links pointing to the old address.

Section types

SectionFields and behaviour
TextEdit the optional heading and body directly on the canvas. Select body text and use Bold, Italic, Underline, Bullets, Numbered list or Clear formatting in the contextual menu beside your selection. Line breaks are preserved.
ImageExisting asset path or HTTPS image URL, alternative text and optional caption. Choose from repository images using the selector.
LinkButton label and destination. Use an HTTPS URL, a local HTML page, or an anchor.

Choose Text, Image or Link in an insertion control, then select Add section here. Controls appear between every pair of sections and at the end. Use the arrows on a section to move it, Duplicate to copy it, or Remove to delete it from the current draft. Use Undo in the Studio header to recover a removed section. Click an image or its Settings to choose its asset and alternative text. Link Settings edits its destination; the label and image caption are edited directly on the canvas. There is no media upload control; add new image files to the repository separately, then reconnect to refresh the image list. External images must remain publicly accessible.

Examples: assets/portrait.webp, https://example.com/photo.webp, story.html, and index.html#music. Links using javascript:, scheme-relative URLs or parent-directory traversal are rejected. Email and telephone schemes are not currently supported.

Menus & page order

In Pages & navigation, select Customise existing menu to start from the current template’s links. Edit labels and destinations, add or remove links, and use the arrows to reorder them. Restore template menu removes your custom base menu and returns to the template’s original links.

Visible generated pages are appended after that base menu. Use the page arrows to set their order. Avoid adding the same generated page to the base menu as well, or you will get duplicate links. Hiding a page from navigation does not make it private: its URL remains accessible after publication.

Delete a page

Select its page editor, choose Delete page, and confirm. It disappears from the current draft; publishing removes it from the next clean build and the generated menu. Existing external links may then lead to a missing page. Undo can restore the edit during the current session.

Preview accurately

The preview uses your artist’s homepage template and stylesheet. Desktop and Mobile change the preview width. Generated pages replace the main content while retaining the artist shell.

The visual preview is sandboxed. To hear music, use the Preview music track selector and audio controls above it. These controls play your saved catalog and keep playing while the visual preview updates. The website player remains visible in the canvas; the separate Preview music controls provide playback while editing. Browser autoplay rules still require pressing Play. The canvas shows published collections, the website’s fonts and styles, the visible player, and muted video playback. Static template text, media and link destinations can be edited in place; collection titles/descriptions and artwork also have bindings. The formatting bubble follows the selected text rather than occupying a permanent row. Select Preview to hide editor controls. The entrance is skipped while editing, and custom scripts remain paused. Compare at the same viewport width when checking responsive layouts. Check the published site for playback, entrance animation and final media behaviour.

DJ events & calendar

Open DJ events & calendar, enable Homepage events, choose a heading, public display timezone and maximum event count. Add each appearance with its title, start, optional end, venue, city or online location, description, and optional HTTPS event/ticket URL. Date inputs use your device timezone, shown above the event list; the public cards display the selected public timezone. These can differ. Dates are saved as absolute UTC instants.

Only upcoming or ongoing events are displayed, in chronological order. An event with an end remains visible until that end; one without an end disappears at its start. Cancelled events are hidden. The homepage has no events section when the calendar is disabled or there are no upcoming events. The public page refreshes expiry visibility every minute. Visitors can download an ICS entry using Add to calendar, for import into their calendar app. This is a manually maintained gig calendar, not a Google Calendar sync.

Social & music links

Open Social & music links, set a footer heading such as Available on, and add a link for each profile. Choose from the platform list or Custom link, enter the full HTTPS URL, and optionally override the label. Email uses a mailto address. Custom links require a label. Use the arrows to set footer order; Remove deletes a link.

The footer uses monochrome SVG icons and text labels, with a hover effect matching the site. Forty-five bundled brand icons are available; other named platforms and custom links use a generic globe. Icons are served with the site and do not call a third-party icon service. There is no empty footer section if no links are configured. Configuration does not verify ownership of external profiles.

Undo

Undo restores earlier editing snapshots, up to 50 per session. It does not undo GitHub commits or a live deployment. There is no Redo button. Export or save a draft before making a large change.
