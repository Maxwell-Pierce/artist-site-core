# Bundled lyric typefaces

24 font families obtained from the official google/fonts repository on 27 October 2026, for the shared Artist Studio lyric font gallery. The original SIL Open Font License and copyright statement for each family are included as FAMILY-OFL.txt. sources.json records the upstream location; font-catalog.mjs records the chosen face and supported weight range.

Font outlines and names are unchanged. Original TrueType fonts were converted to WOFF2 using fontTools/Brotli for browser delivery, with no glyph subsetting. Browser FontFace loads local assets only when needed. Preview cards, canvas lyric rendering and MP4 export reuse the loaded face. The existing sans/serif/mono presets remain operating-system fonts and do not require these assets.

Upstream: https://github.com/google/fonts
Google Fonts: https://fonts.google.com/
License reference: https://openfontlicense.org/
