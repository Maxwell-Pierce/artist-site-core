# HEAVNS - Moving Out Of Frame

Full-track Artist Studio demo contributed by Maxwell Pierce, bundled at the artist’s request for use across sites consuming the shared core.

- `audio.ogg`: original stereo Opus audio, unchanged from the artist’s catalog (approximately 4:06).
- `artwork-original.png`: original artwork, unchanged.
- `track.json`: original text and aligned source lines, local media paths, exact decoded duration and source/checksum metadata.
- `source-lyrics.json`: original automatic analysis, preserved unchanged.
- `lyrics.json`: editor-ready version with all 393 words timed across 72 lines. Valid source anchors are preserved where possible; 107 word timings are marked Estimated. Gaps and unusable overlaps are estimated locally using the editor’s word distribution. These are not newly recognized or manually verified timings.

Source: https://treblo.com/song/94d913ab-b764-49e9-9e3b-145a3b1012a5

The full original transcript remains available for recovering or correcting missed sentences. Analysis timings are a practical editing starting point, not a claim of perfect alignment. Original catalog timing data is retained separately.

All media is served locally with the static admin demo, so waveform decoding, artwork previews and video exports do not depend on third-party media CORS. No login or backend is required. Demo edits are isolated to the current tab and can be downloaded without modifying any artist’s site, track catalog or repository.

The media is attributed to Maxwell Pierce and supplied for the shared Artist Studio demo. Bundling it does not relicense the music or artwork under a software license.
